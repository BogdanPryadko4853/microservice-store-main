## Обзор

Это приложение демонстрирует архитектуру микросервисов, где каждый сервис отвечает за свою область функциональности. Оно включает в себя следующие основные сервисы:

*   **`auth-service`**: Сервис аутентификации и авторизации пользователей.
*   **`config-server`**: Сервис для централизованного управления конфигурациями.
*   **`customer`**: Сервис управления информацией о клиентах.
*   **`discovery`**: Сервис для регистрации и обнаружения сервисов.
*   **`gateway`**: API Gateway для маршрутизации запросов.
*   **`order`**: Сервис управления заказами.
*   **`notification`**: Сервис для отправки уведомлений.
*   **`payment`**: Сервис для обработки платежей.
*   **`product`**: Сервис управления продуктами.
*   **`user-service`**: Сервис управления пользователями.

### Технологии

*   **Spring Cloud**: Для создания микросервисной архитектуры.
*   **Docker & Docker Compose**: Для контейнеризации и управления сервисами.
*   **PostgreSQL**: Основная база данных для хранения данных.
*   **MongoDB**: Используется для хранения дополнительных данных (например, настроек).
*   **Zipkin**: Для распределенной трассировки.
*   **Kafka**: Для асинхронного взаимодействия между сервисами.
*   **Maildev**: Для тестирования отправки email.

## Запуск Приложения

### Предварительные требования

1.  Установленный Docker и Docker Compose.
2.  Установленный Git.

### Шаги по запуску

1.  **Клонирование репозитория:**

    ```bash
    git clone <ссылка на ваш репозиторий>
    cd <название вашего репозитория>
    ```

2.  **Запуск Docker Compose:**

    ```bash
    docker-compose up -d --build
    ```

    Эта команда запустит все необходимые сервисы в Docker-контейнерах.

## Описание сервисов

* **auth-service**: Сервис аутентификации и авторизации.
* **config-server**: Централизованное хранилище конфигураций.
* **customer-service**: Сервис управления данными о клиентах.
* **discovery-service**: Сервис для обнаружения других сервисов.
* **gateway**: Сервис, являющийся точкой входа в приложение.
* **notification-service**: Сервис отправки уведомлений.
* **order-service**: Сервис для обработки заказов.
* **payment-service**: Сервис для работы с платежами.
* **product-service**: Сервис управления продуктами.
* **user-service**: Сервис управления пользователями.
